# Recomp Observatory

The dashboard observes multiple read-only recomp targets. Preserve each target's own instructions and execution ownership. Never edit, build, execute or test target project/game code. Isolated dashboard fixtures are allowed.

Keep local target configuration and histories in work/. Never package or publish target paths, reports, original or generated game code, assets, keys or saves. Packaging must use the explicit observer file allowlist.

Statistics, caches, histories and evidence must follow the selected target. Unknown metrics remain null. Never apply one report format's counters or runtime results to another attempt. Supported-emission percentages never mean whole-game completion. Discovery only proposes target boundaries; users review names before saving them.
